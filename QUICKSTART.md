# MediReminder Quick Start

1. Add a medication, dosage, quantity and interval.
2. Leave **start immediately** enabled if the first interval should start now.
3. Allow notifications on Android.
4. When a dose becomes due, choose **Taken** or **Snooze 10 minutes**.
5. Use **Report** to review dose history.
6. Use **Backup** regularly if the data is important.

The app stores medication data locally on the device.
